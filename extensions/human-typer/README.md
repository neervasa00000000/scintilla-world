# Human Typer

Chrome extension that types your text **like a real person**: variable speed, pauses, typos, and backspaces to fix them.

## Install

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. **Load unpacked** → select this folder: `extensions/human-typer`

## Use

1. Open **any website** (Gmail, Google Docs, Canvas, forms, etc.)
2. Open the **Human Typer** popup → paste your text → **Start typing**
3. **Click the text box** on the page where you want it to type (blue outline on hover)
4. Press **Esc** on the page to stop early

Works in **iframes** too (embedded editors, some LMS sites).

## Tips

- Leave **“Click on page to choose”** checked — you don’t need to focus the field first
- Uncheck that option only if your cursor is already blinking in the field
- Typo rate `0%` = perfect typing; `20–30%` = very human, more mistakes
- Won’t run on `chrome://` pages — use a normal tab

## Privacy

All typing runs locally in your browser. Nothing is sent to a server.
